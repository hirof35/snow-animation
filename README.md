Snowfall Animation (雪の降るキャンバス)
HTML5のCanvas APIとJavaScriptを用いて、画面上に静かに雪が降り続ける様子を描画するシンプルなアニメーション作品です。

概要
黒い背景（夜空や暗闇をイメージ）の中に、さまざまな大きさやスピードを持った白い雪の粒子がランダムに生成され、ゆらゆらと揺れながら画面上部から下部へと舞い落ちます。画面外に消えた雪は再び上部から現れ、ループして降り続けます。

主な機能と特徴
ランダムな雪の性質: 生成される雪の粒子（最大100個）は、それぞれ「落下速度」「大きさ」「横方向へのドリフト（流れ）」「揺れの半径」がランダムに設定されます。

サイン波によるリアルな揺らぎ: Math.sin()（正弦波）を利用することで、直線的に落ちるのではなく、風に煽られて左右にゆらゆらと揺れるリアルな雪の動きを表現しています。

軽量・依存関係なし: 外部ライブラリ（jQueryなど）を一切使用せず、標準的なHTML/CSS/JavaScriptのみで実装されているため、ブラウザ単体で非常に軽量に動作します。

仕様
キャンバスサイズ: 600px × 600px

背景色: 黒 (black)

雪の色: 白 (white / 不透明度 60%)

最大雪数: 100個

描画レート: 50ミリ秒ごと（約20FPS）に更新

ディレクトリ構成（例）
Plaintext
.
└── index.html   # 本プログラム（HTML/CSS/JS一体型）
使い方・実行方法
上記のソースコードを index.html という名前で保存します。

保存した index.html ファイルを、Google Chrome、Microsoft Edge、Safari、Firefoxなどの主要なWebブラウザで開きます（ダブルクリック等）。

ブラウザ上に黒い四角形が表示され、自動的に雪が降り始めます。

技術的な解説（コードのポイント）
Snow オブジェクト: 各雪の粒子のパラメータ（座標、速度、大きさ、揺れの周期など）を保持するコンストラクタです。

addSnow(): 200ミリ秒ごとに新しい雪を1つずつ生成し、配列 snows に追加します。上限の100個に達すると生成タイマーは停止します。

tick() と paint(): 50ミリ秒ごとに雪の座標を更新（tick）し、キャンバス全体を黒で塗りつぶした後にすべての雪を再描画（paint）することで、滑らかなアニメーションを実現しています。
